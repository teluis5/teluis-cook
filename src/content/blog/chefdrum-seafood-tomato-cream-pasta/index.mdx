<ProblemBox>
- トマトクリームパスタを作りたいけれど、生クリームが冷蔵庫にない
- フライパンでトマトソースを煮詰めると、コンロ周りに赤く油ハネして掃除が大変
- 海鮮のパスタは具材がパサついたり、水っぽくなったりして味が決まりにくい
</ProblemBox>

本格的なトマトクリームパスタは、<b>生クリームがなくても牛乳だけで驚くほど濃厚に作れる</b>。

秘密は、旨味たっぷりの「海鮮ミックス」と、麺を和える瞬間に加える<b>「追いオリーブオイル」</b>だ。
オイルと牛乳、トマトソースがしっかり混ざり合って乳化し、まるでお店のようなクリーミーなコクが生まれる。

さらにシェフドラム（CHEF DRUM）を使えば、あの厄介な<b>「トマトソースの飛び散り」</b>が完全にゼロになる。
今回は、ニップンの定番レシピをベースに、身近な食材だけで作れる極上アレンジを紹介する。

## 材料（2人前）

特別な材料は一切不要。普段から冷凍庫や冷蔵庫にある食材だけで完結する。

| 材料名 | 分量 | 備考・下ごしらえ |
| :--- | :--- | :--- |
| <b>スパゲッティ</b> | 200g | 1.6〜1.8mmの太めがおすすめ |
| <b>海鮮ミックス（冷凍）</b> | 150〜200g | 解凍して水気を軽く拭き取る |
| <b>玉ねぎ</b> | 1/2個 | みじん切り |
| <b>にんにく</b> | 2かけ | みじん切り（増量して香りを強化） |
| <b>トマト缶（ホールまたはカット）</b> | 1缶（400g） | ホールなら粗く潰しておく |
| <b>牛乳</b> | 150ml | 生クリームの代用 |
| <b>顆粒コンソメ</b> | 小さじ1/2〜1 | 魚介の塩気に合わせて調整 |
| <b>オリーブオイル（炒め用）</b> | 大さじ2 | 内なべに最初に入れる |
| <b>追いオリーブオイル（仕上げ用）</b> | 大さじ1〜2 | 麺を絡める直前に投入 |
| <b>塩・こしょう</b> | 各適量 | 味の微調整用 |
| <b>乾燥パセリ</b> | お好みで | 彩り用 |

## 作り方：シェフドラムで作る海鮮トマトクリームソース

パスタを茹でる鍋を横で沸かしつつ、シェフドラムでソースを作っていく。

### ステップ1：にんにくの香りをじっくり引き出す

<figure>
  <Image src={garlicImg} alt="シェフドラムの内鍋にオリーブオイルとたっぷりの刻みにんにくを入れて加熱する様子" />
  <figcaption>オリーブオイルとにんにく2かけをセット。焦がさずじっくり熱を通す</figcaption>
</figure>

1. 内なべにオリーブオイル（大さじ2）と、みじん切りにしたにんにく（2かけ）を入れる。
2. シェフドラムを手動加熱（約100〜120℃）にセットし、香りが立ち込めるまで温める。

> 💡 <b>にんにく2かけが旨さの土台</b><br />
> 生クリームを使わない分、にんにくを贅沢に2かけ使うのがポイントだ。オイルに香りが溶け込み、ソース全体のコクがグッと底上げされる。

### ステップ2：玉ねぎを加えてしんなりするまで炒める

<figure>
  <Image src={onionImg} alt="内鍋にみじん切り玉ねぎを投入して炒めている様子" />
  <figcaption>玉ねぎを投入。自動回転で焦げ付きを防ぎながら甘みを引き出す</figcaption>
</figure>

1. みじん切りにした玉ねぎを内なべに投入する。
2. 自動回転させながら、玉ねぎが透き通って甘い香りが立つまで炒める。

フライパンだと付きっきりで木べらを動かす必要がある。シェフドラムなら勝手に回ってくれるため、この間にパスタ用の湯を沸かせる。

### ステップ3：海鮮ミックスを投入してサッと火を通す

<figure>
  <Image src={seafoodImg} alt="内鍋に海鮮ミックス（エビ・イカ・アサリ）を投入して炒める様子" />
  <figcaption>解凍した海鮮ミックスを投入。魚介から出たエキスがオイルに絡む</figcaption>
</figure>

1. 水気を切った海鮮ミックスを内なべに加える。
2. 全体をさっと炒め合わせ、魚介のエキスをオイルにしっかり移す。

エビ単体で作るよりも、アサリやイカが入った海鮮ミックスを使う方が出汁が複雑になり、奥深い味に仕上がる。

### ステップ4：トマト缶と牛乳を加えて煮詰める

<figure>
  <Image src={sauceImg} alt="トマト缶、コンソメ、牛乳150mlを加えて煮詰めた濃厚なトマトクリームソース" />
  <figcaption>トマトの酸味を飛ばし、牛乳をなじませた状態。鮮やかなオレンジ色に変化する</figcaption>
</figure>

1. トマト缶（400g）と顆粒コンソメを加える。
2. ふたをして傾き設定・回転で5〜8分ほど煮詰め、トマトの余分な水分と酸味を飛ばす。
3. 牛乳（150ml）を注ぎ入れ、さらに2〜3分温めてソースを一体化させる。味を見て塩・こしょうで調える。

トマトソースがグツグツ跳ねても、シェフドラムの内鍋が深いので周囲が一切汚れない。この快適さは一度体験すると手放せなくなる。

### 仕上げ：麺を合わせ、「追いオリーブオイル」で乳化させる

<figure>
  <Image src={heroImg} alt="皿に盛り付けられた濃厚海鮮トマトクリームパスタ。具材がゴロゴロで照りがある" />
  <figcaption>完成！麺に濃厚ソースがしっかり絡みつき、魚介の具材も贅沢に入っている</figcaption>
</figure>

1. 表示時間より1分短めに茹で上げたスパゲッティを内なべに投入する。
2. ここで<b>「追いオリーブオイル（大さじ1〜2）」</b>を回しかける。
3. トングで全体を素早くかき混ぜ、ソースと麺を激しく絡め合わせる。

オイルを加えることでソースが一気に乳化し、とろみがついて麺にピタッと吸着する。お皿に盛り、パセリを散らせば完成だ。

## 牛乳でも濃厚に仕上がる「2つの勝因」

「生クリームがないから諦める」必要は全くない。牛乳でも大満足の味になる理由は明確だ。

### ① 魚介ミックスのエキスが牛乳の軽さを補う
エビだけでなく、アサリやイカから出る濃厚なグルタミン酸がソースに溶け出す。牛乳のあっさりした脂肪分を魚介の強い旨味が力強く支えてくれる。

### ② 仕上げの「追いオリーブオイル」による強制乳化
麺を入れる直前に良質なオリーブオイルを足すことで、トマトの水分と油分、牛乳のタンパク質が素早く乳化する。これがパスタ屋さんのような「こっくり感」を生み出す。

<ConclusionBox>
- 生クリームがなくても、牛乳150ml＋にんにく2かけで極上のトマトクリームが完成
- 麺投入時の「追いオリーブオイル」でソースがとろっと乳化し、麺にしっかり絡む
- シェフドラムを使えばトマトソースの油ハネ掃除から完全に解放される
</ConclusionBox>
